# any audit — εγκατάσταση

Εφαρμογή εσωτερικών επιθεωρήσεων της **Άριστης Συμβουλευτικής** για Windows 10/11.

## Κατέβασμα

Πάντα η τελευταία έκδοση: **https://github.com/Babis1301/any-audit-releases/releases/latest**

Κατεβάστε το αρχείο `any-audit-Setup-<έκδοση>.exe` από την ενότητα **Assets**.

## Εγκατάσταση

1. Τρέξτε το αρχείο που κατεβάσατε.
2. Στην μπλε προειδοποίηση των Windows («Ο υπολογιστής σας προστατεύτηκε») πατήστε **Περισσότερες πληροφορίες** και μετά **Εκτέλεση ούτως ή άλλως**. Η προειδοποίηση εμφανίζεται επειδή η εφαρμογή είναι εσωτερική και δεν έχει εμπορική ψηφιακή υπογραφή.
3. Ακολουθήστε τον οδηγό εγκατάστασης. Θα δημιουργηθεί συντόμευση στην επιφάνεια εργασίας.

## Πρώτη είσοδος

1. Ανοίξτε την εφαρμογή και πατήστε **Εγγραφή**.
2. Δώστε ονοματεπώνυμο, το εταιρικό σας email και έναν κωδικό τουλάχιστον 8 χαρακτήρων.
3. Ανοίξτε το email επιβεβαίωσης που θα λάβετε και πατήστε τον σύνδεσμο.
4. Γυρίστε στην εφαρμογή και συνδεθείτε.
5. Στην οθόνη **Συμμετοχή με κωδικό** βάλτε τον κωδικό της μονάδας σας. Τον δίνει ο διαχειριστής προσωπικά, μην τον κοινοποιείτε.

## Ενημερώσεις

Όταν βγαίνει νέα έκδοση, δημοσιεύεται εδώ. Αν η εφαρμογή σας δεν ενημερώνεται μόνη της, κατεβάστε και τρέξτε τον νέο installer· η εγκατάσταση αντικαθιστά την παλιά έκδοση χωρίς απεγκατάσταση και χωρίς απώλεια δεδομένων (όλα τα δεδομένα βρίσκονται στη βάση, όχι στον υπολογιστή).

## Υποστήριξη

Για οποιοδήποτε πρόβλημα απευθυνθείτε στον διαχειριστή της εφαρμογής.
